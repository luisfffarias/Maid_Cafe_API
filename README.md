# Maid In Brasil

## 📝 Sobre o Projeto

O **Maid in Brasil** é um sistema web completo desenvolvido para modernizar e simplificar o gerenciamento de serviços e interações. Unindo a robustez do desenvolvimento back-end à atenção aos detalhes do design de interface, o projeto foi concebido sob uma estética temática e imersiva inspirada na cultura *"maid/kawaii"*, trazendo um visual carismático e único para uma aplicação altamente funcional.
## ⚙️ Funcionalidades Principais (Features)

### 🛍️ Gerenciamento de Pedidos (Order Management)
- [x] **Abertura e Fluxo de Pedidos:** Registro detalhado de novos pedidos com status em tempo real (Pendente, Em Preparo, Entregue, Cancelado).

### 📦 Gerenciamento de Estoque (Inventory Control)
- [x] **Controle de Insumos e Produtos:** CRUD completo para cadastro, edição e exclusão de itens do estoque com especificação de quantidade e custo.
## Tech Stack

**Client:** Expo, React Native

**Server:** Nest.JS, Prisma ORM, Swagger Docs, Render host

**Database:** Supabase, Postgre SQL
